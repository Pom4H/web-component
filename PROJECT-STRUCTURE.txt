🔍 ARCHITECTURE COMPARISON
────────────────────────────────────────────────────────────────────────────────

BEFORE (Proxy-based):
┌─────────────────────────────────────┐
│ State (Plain Object)                │
│         ↓                           │
│ Proxy with handlers                 │
│         ↓                           │
│ Event emission (manual)             │
│         ↓                           │
│ requestAnimationFrame (~16ms)       │
│         ↓                           │
│ Batch process events                │
│         ↓                           │
│ Notify consumers                    │
│         ↓                           │
│ Update DOM                          │
└─────────────────────────────────────┘

AFTER (Signal-based):
┌─────────────────────────────────────┐
│ SignalStateWrapper                  │
│         ↓                           │
│ Signal.State per property           │
│         ↓                           │
│ Signal.subtle.Watcher               │
│         ↓                           │
│ queueMicrotask (<1ms)              │
│         ↓                           │
│ Notify effects automatically        │
│         ↓                           │
│ Update DOM                          │
└─────────────────────────────────────┘
