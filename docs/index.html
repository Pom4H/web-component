Component files

A custom-element name maps directly to an HTML file by replacing hyphens with slashes.

<user-card></user-card>          → user/card.html
<workspace-shell></workspace-shell> → workspace/shell.html

Skein fetches an unknown tag's source before registering it. A missing file leaves the tag undefined instead of stealing a Custom Element that may belong to another library.

Reactive state

Inside a component script, this is reactive state. Plain objects and arrays are proxied recursively and a shared raw object keeps one Skein Proxy identity across components.

<script>
  this.count = 0
  this.user = { name: 'Ada' }
  this.up = () => this.count++
</script>

Date, Map, Set, DOM/platform objects and class instances stay native and opaque.

Bindings

<h1>Hello {user.name}</h1>
<div title="User {user.name}"></div>
<label for={inputId}>Name</label>
<input .value={user.name}>
<button ?disabled={saving}>Save</button>
<button @click={save}>Save</button>
<reactor-core --load={reactor.load}></reactor-core>

Braces contain strict property paths, not JavaScript expressions. Invalid paths and malformed special bindings fail during component compilation.

CSS custom properties

<reactor-core
  style="display:block; contain:layout"
  --temperature={reactor.temperature}
  --load={reactor.load}>
</reactor-core>

/* reactor-core's Shadow DOM */
:host { --load: 0; }
.core { transform: scale(calc(1 + var(--load) * .04)); }

--name={path} updates exactly one declaration with element.style.setProperty('--name', value). A null, undefined or false value removes only that custom property; zero remains valid.

This is not a serialized style binding. Ordinary static inline declarations and other custom properties stay intact. If static style contains the same property, the binding owns that declaration and removal exposes the normal cascade or fallback. Do not combine it with a reactive whole-style={path} binding on the same element. A custom property set on a component host inherits naturally into its Shadow DOM.

Component composition

The complete composition contract is browser-shaped:

data      → DOM properties
/actions/ ← bubbling + composed CustomEvent
content   → native <slot>

There is no component event bus, provide/inject system or framework slot API.

Inputs

<script>
  input('name', 'Metric')
  input('value', 0)
</script>

<ui-metric name="Active" .value={active}></ui-metric>

Literal primitive attributes can seed matching inputs. Conversion follows the fallback type. Live values, objects and functions use .property={path}. Initialization precedence is pre-mount property → static attribute → fallback.

A static attribute is only the initial value. Later attribute changes do not update child state; use a DOM property when the input must stay live. Host API collisions such as state, title or dispose throw.

Outputs

host.dispatchEvent(new CustomEvent('task-select', {
  detail: { id: this.task.id },
  bubbles: true,
  composed: true
}))

Composed bubbling events cross nested Shadow DOM boundaries. Intermediate components do not need relay handlers.

Native slots

<!-- ui/panel.html -->
<header><slot name="heading"></slot></header>
<slot></slot>

<!-- owner -->
<ui-panel>
  <span slot="heading">Tasks</span>
  <task-board .tasks={tasks}></task-board>
</ui-panel>

Skein uses real Shadow DOM, so default slots, named slots, slotchange and assignedElements() are native browser behavior.

Workspace uses this contract across 18 component types.

Keyed lists

<article each={projects} key={id}>
  <b>{index}. {title}</b>
  <input placeholder="DOM state survives reorder">
</article>

each leaves native HTML for={inputId} available. Explicit keys must be non-null and unique; existing keys move real node ranges rather than rebuilding them. List locals include index, $index and $value.

Conditions

<section if={inspectorOpen}>...</section>

A branch owns a child scope. Hiding it disposes effects/listeners and nested Skein components. Third-party Custom Elements are only disconnected.

Computed values and effects

<script>
  this.total = computed(() => this.price * this.quantity)
  effect(() => console.log(this.total))
</script>

computed() is lazy/cached. Synchronous state writes share one microtask, and user effects run after pending render work settles.

Lifecycle

Disconnect pauses reactive work; reconnect resumes dirty bindings without rebuilding. Permanent teardown is host.dispose(). Failed template mounts roll back their fresh scope and partial shadow DOM.

window.addEventListener('resize', this.measure, { signal: abortSignal })
const frame = requestAnimationFrame(this.draw)
onCleanup(() => cancelAnimationFrame(frame))

Browser Playground

The Playground is a zero-dependency editing workspace built from browser primitives rather than an embedded editor package. It keeps syntax-highlighted source, synchronized line numbers, cursor/selection position and the isolated preview together.

Every built-in example has its own auto-saved local draft. Reset reloads its repository source, and Share copies a URL containing the current source. On desktop, drag the divider or focus it and use the arrow, Home and End keys to resize the editor; mobile keeps a fixed stacked split.

Ctrl/Cmd + Enter   run
Ctrl/Cmd + S       save now
Tab / Shift+Tab    indent / outdent
Enter              continue current indentation

Loading, queued, running, live, manual, edited and error states are visible. Runtime errors can be dismissed, and save/share actions provide explicit feedback.
