The public surface is deliberately small. Ordinary JavaScript owns state; HTML describes where it goes.

State

Plain assignments are reactive.

A component script runs with this bound to its deep reactive state proxy.

<script>
  this.count = 0
  this.user = { name: 'Mina' }
  this.items = []

  this.count++
  this.user.name = 'Iris'
  this.items.push({ id: 1 })
</script>

Bindings

Use paths, not template expressions.

Derived logic belongs in computed(). That keeps the template easy to inspect and lets the runtime track dependencies precisely.

<h1>Hello {user.name}</h1>
<div title="User {user.name}"></div>
<input .value={user.name}>
<button ?disabled={saving}>Save</button>
<button @click={save}>Save</button>

Context

in={user} creates a lexical binding context for the element and its descendants.

<address in={user.address}>
  {city}, {street}
</address>

Lists

Keyed ranges preserve DOM identity.

<article for={projects} key={id}>
  <b>{index}. {title}</b>
  <input placeholder="local DOM state survives reorder">
</article>

Objects use object identity by default. A stable key={id} is preferable when records can be replaced. Push creates one view; removal disposes one view; reorder moves existing nodes.

Conditions

Branches own their own scope.

<aside if={inspectorOpen}>
  <canvas></canvas>
</aside>

When the condition becomes false, the branch's effects, listeners, nested scopes and DOM range are disposed together.

Computed

Lazy, cached derived state.

<script>
  this.price = 100
  this.quantity = 2
  this.total = computed(() => this.price * this.quantity)
</script>

<strong>{total}</strong>

Effects

Render settles before user effects.

<script>
  effect(() => console.log(this.total))

  batch(() => {
    this.x = 10
    this.y = 20
  })
</script>

Synchronous writes are deduplicated into one scheduled wave. batch() is useful when a logical transaction spans multiple writes.

Lifecycle

Cleanup belongs to the component scope.

<script>
  const frame = requestAnimationFrame(draw)
  onCleanup(() => cancelAnimationFrame(frame))

  window.addEventListener('resize', measure, {
    signal: abortSignal
  })
</script>

Disconnect pauses reactive work. Reconnect resumes dirty bindings. Explicit host.dispose() permanently tears the component down.
