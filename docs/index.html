DOCS.

Ordinary JavaScript owns state. HTML says where it goes. The public API stays deliberately small.

State

Plain assignments are reactive.

A component script runs with this bound to a deep reactive Proxy. Missing properties and array structure are tracked too.

<script>
  this.count = 0
  this.user = { name: 'Mina' }
  this.items = []

  this.count++
  this.user.name = 'Iris'
  this.items.push({ id: 1 })
</script>

Synchronous writes automatically settle in one microtask render wave. There is no explicit batching API.

Bindings

Paths, not template expressions.

Derived logic belongs in computed(). Paths are compiled once and tracked precisely.

<h1>Hello {user.name}</h1>
<div title="User {user.name}"></div>
<input .value={user.name}>
<button ?disabled={saving}>Save</button>
<button @click={save}>Save</button>

Context

in={user} creates a lexical context for the element and its descendants.

<address in={user.address}>
  {city}, {street}
</address>

Lists

Keyed ranges preserve DOM identity.

<article for={projects} key={id}>
  <b>{index}. {title}</b>
  <input placeholder="local DOM state survives reorder">
</article>

Objects use object identity by default. Use a stable key={id} for application records. Append creates new views, removal disposes removed views, and reorder moves the existing nodes. index and $index are reactive locals.

Conditions

Branches own their scope.

<aside if={inspectorOpen}>
  <canvas></canvas>
</aside>

When the condition becomes false, effects, listeners, nested Skein elements and the DOM range are disposed together.

Computed

Lazy cached derived state.

<script>
  this.price = 100
  this.quantity = 2
  this.total = computed(() => this.price * this.quantity)
</script>

<strong>{total}</strong>

Effects

Render settles before user effects.

<script>
  effect(() => console.log(this.total))

  this.x = 10
  this.y = 20
</script>

Those synchronous writes share one scheduled flush automatically.

Lifecycle

Cleanup belongs to the owning scope.

<script>
  const frame = requestAnimationFrame(draw)
  onCleanup(() => cancelAnimationFrame(frame))

  window.addEventListener('resize', measure, {
    signal: abortSignal
  })
</script>

abortSignal is allocated lazily. Disconnect pauses reactive work, reconnect resumes it, and host.dispose() permanently tears the component down.

Public API

Two module properties.

Skein.version
Skein.define(tag, source)

Inside component scripts Skein injects computed, effect, onCleanup, host and abortSignal. Low-level signals and scheduler controls stay internal.
