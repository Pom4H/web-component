These browser-side widgets keep WebGL and Canvas imperative, SVG as SVG and Web Audio native. Each source is a plain HTML component file that can ship on a static host without npm or compilation. Open the smaller examples in the Playground; use Workspace and Voxel Meadow as composition proofs.

Voxel Meadow

A bright touch-friendly WebGL2 sandbox: typed entities and systems drive a 120 Hz fixed-step world with gravity, breeze fields, collisions and collectible blocks. Play it with keyboard, drag or the mobile gamepad.
