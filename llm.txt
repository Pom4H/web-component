# Skein

> Skein is a zero-dependency, HTML-first Web Components runtime with fine-grained reactivity. It is designed for creative CSS, SVG, Canvas and native-DOM sites where HTML remains the document and Skein binds only dynamic data.

Canonical machine-readable project index: https://pom4h.github.io/web-component/llms.txt

This singular `/llm.txt` file is provided as a compatibility alias for tools or users that guess the filename. Prefer `/llms.txt`.
