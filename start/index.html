The shortest path from an empty folder to reactive Web Components. Split components into files later without changing their syntax.

skein.min.js · 14.0 kB raw · 5.1 kB gzip · 4.6 kB brotli · 0 dependencies

Create index.html.

No package manifest. No scaffold. Any static server or GitHub Pages is enough.

Write the element and its inert template.

index.html
<click-count></click-count>

<template skein="click-count">
  <script>
    this.count = 0
    this.up = () => this.count++
  </script>

  <button @click={up}>
    clicked {count} times
  </button>

  <style>
    button {
      border: 0;
      padding: 1rem 1.4rem;
      border-radius: 999px;
      background: #eaff63;
      font: inherit;
    }
  </style>
</template>

<script type="module"
  src="https://cdn.jsdelivr.net/gh/Pom4H/web-component@main/skein.min.js">
</script>

That is the app.

Skein compiles the template once, defines the custom element and connects {count} directly to the state property read by that text binding.
