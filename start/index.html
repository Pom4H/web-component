ONE FILE.

The shortest path from an empty folder to reactive Web Components. Split and compose components later without changing the medium.

Create index.html.

No package manifest. No scaffold. Any static server or GitHub Pages is enough.

Write the element and its inert template.

index.html
<click-count></click-count>

<template skein="click-count">
  <script>
    this.count = 0
    this.up = () => this.count++
  </script>

  <button @click={up}>
    clicked {count} times
  </button>
</template>

<script type="module"
  src="https://cdn.jsdelivr.net/gh/Pom4H/web-component@main/skein.min.js">
</script>

That is the app.

Skein compiles the template once and connects {count} directly to the state property read by that text binding.

When it grows

Move components out. Compose them as elements.

Tag names map to files. Data flows down through DOM properties; children send native events up.

<li each={items} key={id}>
  {index}. {title}
</li>
